# FourierFlight — Coming Soon Page

A minimal placeholder landing page for fourierflight.com.

## What this is

Single-file (`index.html`) coming-soon page. Dark background, centered card,
Space Grotesk typeface via Google Fonts CDN. No build step, no framework,
no dependencies beyond that one font request.

## Deployment (TBD)

You have several zero-friction options:

- **GitHub Pages** — push to a repo, enable Pages in Settings, done.
- **Netlify** — drag the folder into netlify.com/drop and it's live in seconds.
- **Vercel** — `vercel --prod` from this folder, or connect the repo.

Any of the three will serve a static `index.html` for free on a custom domain.
